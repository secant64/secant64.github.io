# 小游戏厅

**线上地址：https://secant64.github.io** （GitHub Pages，推送即自动发布）

一个纯前端的网页小游戏合集：首页是游戏列表，点进去直接玩。
没有框架、没有构建步骤、没有后端 —— 全部是静态文件，丢进 GitHub Pages 就能用。

| 页面 | 地址 |
|---|---|
| 游戏厅首页 | https://secant64.github.io |
| 合成大西瓜 | https://secant64.github.io/games/daxigua.html |
| 图片华容道 | https://secant64.github.io/games/huarongdao.html |
| 3×3 魔方 | https://secant64.github.io/games/cube.html |

## 三个游戏的现状

| 游戏 | 状态 | 说明 |
|---|---|---|
| 合成大西瓜 | ✅ 可玩 | 补了缺失的样式表，并把 Matter.js 下载到本地，不再依赖外网 CDN |
| 图片华容道 | ✅ 可玩 | 原本要手动上传图片才能开始，现在内置了一张默认图，进页面直接开局 |
| 3×3 魔方 | ✅ 可玩 | 原来的四个脚本全丢了，这一版是从零重写的简化版：拖拽转层、打乱、计时、最佳成绩 |

魔方这一版**没有做一键求解**。原文件里那套是 Kociemba 两阶段算法，
需要在运行时生成几十 MB 的搜索表，代码量和维护成本都不是这个练习站该承担的；
现在的版本把「渲染 + 交互」做扎实，求解器留作以后单独练手。

## 怎么运行

**最简单**：双击 `index.html`，用浏览器打开就能玩。
所有资源都是相对路径，`file://` 协议下也正常工作。

**更接近线上环境**：

```bash
cd games-site
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> ⚠️ **不要用编辑器里的「预览面板」打开这个站。**
> 它把每个文件当成一个独立文档来渲染，页面里 `assets/css/portal.css` 这类相对路径、
> 以及点击卡片跳到 `games/daxigua.html` 都解析不了，会显示「暂无数据 / 文件已被删除」。
> **文件并没有坏**，用浏览器打开或起一个本地服务就正常。
> 部署到 GitHub Pages 后是真正的网站，不存这个问题。

## 操作说明

**合成大西瓜**
- 移动鼠标 / 手指左右瞄准，点击或松手落果
- 键盘 `←` `→` 调整位置，`空格` 落下
- 右上角 `▶` 是一键演示，会自动合成出大西瓜
- 右侧面板可以上传图片替换最终的大西瓜，图片只存在浏览器本地

**图片华容道**
- 点击与空格相邻的滑块使其滑动
- 也可以用方向键
- 按住「看原图」可临时显示目标图
- 「一键自动还原」会用 IDA* 搜出解并自动走完

**3×3 魔方**
- 在方块表面按住往一个方向拖，那一层就转 90°；拖的是哪一块就转哪一层，中间层也能单独转
- 拖空白处（或按住右键 / Shift 拖）是转视角，不会打乱
- 方向键也可以微调视角
- 「打乱」之后开始计时；六个面各自纯色即复原，成绩存在 localStorage（键名 `cube-best`）
- 只有从「打乱」开始的一局才记成绩，否则随便转几下就能刷出 0 秒

## 想加第四个游戏

1. 在 `games/` 下放一个新的 HTML（自己带样式和脚本最省事）
2. 打开 `index.html`，复制一张 `.game-card`，改三处：
   - `href` 指向新文件
   - `--c` 换成这个游戏的主色（卡片 hover 的光晕会跟着变）
   - 标题、描述、标签
3. 缩略图是内联 SVG，把 `<div class="thumb">` 里的内容整段替换即可；
   懒得画就放一张 `assets/img/xxx.png`，用 `<img>` 代替 `<svg>`

## 部署到 GitHub Pages

**单独部署**：把 `games-site/` 里的内容推到某个仓库，开启 Pages 即可。

**和个人主页合并**（推荐，最终只维护一个仓库）：

```
你的用户名.github.io/
├── index.html          ← 个人主页
├── style.css
├── main.js
└── games/              ← 把 games-site 整个目录改名放进来
    ├── index.html
    ├── assets/
    ├── games/
    └── lib/
```

放进去之后访问 `https://你的用户名.github.io/games/`，
个人主页里加一个链接指过去就行，不用改任何路径。

## 已知的小坑

- 西瓜的画布是**固定 440×660 逻辑尺寸**，靠 CSS 缩放适配手机；改宽度要去 `daxigua.js` 里改 `W` 和 `H`，改 CSS 没用。
- 魔方的面片**必须紧贴**（`translateZ(S/2)`）。留 1px 缝隙看起来更精致，但四个方块交汇处会形成针孔，直接看穿整个立方体看到背面的颜色。
- 魔方的 `.face` **不能加 `border-radius`**，圆角会在四块交汇处留出菱形小孔，同样会漏色。圆角只加在里面的 `.sticker` 上。
- 魔方的转层动画用 `requestAnimationFrame`，另外挂了一个 `setTimeout` 兜底：后台标签页里 rAF 会被节流，没有兜底会卡在转一半的状态。
- 华容道的滑块点击靠元素上的自定义属性 `t.value` 找回自己是谁，原文件漏了这一行，导致只能自动还原、没法手动玩。
- 华容道的棋盘依赖 `background-position` 切图，换默认图时记得换成**正方形**图片，否则会被拉伸。
- 两个游戏的分数和最高分存在 `localStorage` 里，换域名会重置。
- 全部逻辑在浏览器本地跑，不上传任何数据；上传的西瓜图案也只存在你自己的浏览器里。
